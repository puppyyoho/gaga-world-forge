# 嘎嘎世界与角色工坊

一个面向 SillyTavern 1.18.0 及以上版本的世界书与角色卡创作扩展。

扩展使用 SillyTavern 当前连接的模型、当前 API 和当前生成预设。界面中没有额外 API Key 配置。用户可以写一段自由要求，也可以组合世界、叙事气质、性格、关系、经济阶层和内容模块，生成一份可以继续编辑的统一项目蓝图。

## 当前功能

- 从自由要求和组合预设生成世界、主角色、NPC、关系与剧情资料。
- 可选生成 User Persona、恋爱、亲密与各类 NSFW 模块。未勾选的模块不会进入创作要求。
- 不设置年龄验证、年龄必填或成人身份声明。年龄只作为普通可选设定，由用户的创作要求决定。
- 使用当前 SillyTavern Chat Completion、Text Completion 或兼容连接管理器进行流式生成。
- 使用 JSONL 事件流。模型每输出一行完整事件，界面就会增加一个可编辑项目。
- 主角色卡支持默认开场白和多条备用开场白，可按沉浸叙事、日常生活、校园青春、悬疑秘密等风格组合批量生成。
- 开场白工坊支持多种 U 设定预设和自定义 U 设定，每条开场白可以单独编辑、新增或删除。
- 支持停止生成。停止后保留已经完成的草稿事件，不会把不完整结果写入酒馆。
- 内置精简、标准、详细、超详细、自动分配和自定义长度。
- 支持世界、角色、NPC、关系、行为、情感、NSFW和剧情钩子的独立长度设置。
- 提供暮色紫粉、月光蓝、森林青绿、琥珀暖金和玫瑰酒红五套界面配色，切换后立即生效并保存在酒馆设置中。
- 工坊内的按钮、输入框和下拉框使用局部高对比样式，避免被 SillyTavern 全局主题压暗文字。
- 标题栏支持鼠标与触屏拖动，窗口可以明显移出原位置；双击标题栏即可复位。
- 自动检查 JSONL 结构、唯一 ID、事件顺序、世界书字段、禁用句式、禁用破折号和条目长度。
- 内置关键词触发模拟器，可区分常驻、直接触发与递归触发，并估算激活内容的 token 数。
- 检测到局部文风或长度问题时，会使用当前模型请求 patch，只改问题字段。
- 模型输出语义蓝图。程序统一计算 SillyTavern 的 UID、Order、Position、概率组和持续效果字段。
- 可导出项目蓝图 JSON、JSONL、原生世界书 JSON和 V2 角色卡 JSON。
- 可直接在 SillyTavern 中创建新世界书。
- 可将新世界书绑定为当前角色的主世界书。
- 可直接创建新角色，并自动绑定刚刚创建的主世界书。
- 角色卡内嵌同一份世界书，方便单文件携带。

## 创作内容

世界模块包括世界核心、社会制度、文化日常、经济阶层、地区地点、组织阵营、种族生态、魔法科技体系、术语和物品资产。

人物模块包括主角色卡、NPC群像、关系网络、行为习惯、情感状态、语言指纹和可选 User Persona。

剧情模块包括历史与当前事件、共同记忆、剧情钩子、秘密伏笔、随机事件池和动态状态。

可选模块包括恋爱互动、亲密关系、NSFW偏好、行为反应、语言、身体设定、事后互动和情境。

## 世界书编译规则

生成模型只负责以下语义字段：

- 稳定事件 ID
- 类别、标题和正文
- 别名、主关键词和次关键词
- 激活意图、重要程度和概率
- sticky、cooldown 和 delay 的消息数量
- 依赖条目和递归终止意图

扩展将这些字段编译为 SillyTavern 原生世界书结构：

- UID 根据稳定 ID 生成，同一项目重复编译时保持稳定。
- 中文关键词默认关闭整词匹配。
- RANDOM 或 probability 条目自动进入项目随机池。
- 依赖条目的具体关键词会编译为次关键词，让相关条目在同一语境或递归扫描中形成约束。
- 叶子条目可以阻止后续递归。
- order 根据重要程度分层，critical、high、medium、low 依次对应更高的插入优先级，同层条目保持稳定顺序。
- position 0 对应 SillyTavern 的 before_char，内嵌角色书会同步写入 insertion_order 和位置字段。
- 随机事件进入同一 inclusion group，groupWeight 默认使用官方默认值 100。随机池中的条目保持等权，单条概率由 probability 控制。
- 具备次关键词或依赖条目的事件会启用 selective，AND_ANY、AND_ALL、NOT_ANY、NOT_ALL 映射到 SillyTavern 当前逻辑编号。
- sticky、cooldown 和 delay 使用消息数量，并按照当前版本的 timed effects 规则编译。

## 长度设置

总长度提供以下选择：

- 自动分配
- 精简
- 标准
- 详细
- 超详细
- 自定义

自定义模式可以设置角色卡目标字数、世界书条目数、普通条目字数范围、重要条目上限、NPC数量和关系条目数量。

分模块长度可以跟随总长度，也可以单独选择精简、标准、详细或自定义目标字数。所有字数只作为写作约束，不会覆盖 SillyTavern 当前 API 的输出 token 设置。

## 安装

GitHub 仓库建好后，可以在 SillyTavern 的 Extensions 面板中选择安装扩展，再粘贴仓库地址。

已经安装旧版本时，可以在 Manage Extensions 中点击更新，再刷新或重启 SillyTavern。标题栏显示 `v0.1.6` 即代表本次界面修复已经加载。

手动安装时，把整个目录放到当前用户的扩展目录：

```text
SillyTavern/data/<你的用户>/extensions/gaga-world-forge/
```

也可以使用旧式全局扩展目录：

```text
SillyTavern/public/scripts/extensions/third-party/gaga-world-forge/
```

刷新 SillyTavern 后，从扩展设置或右下角“界”悬浮按钮打开工坊。

## 使用流程

1. 填写自由创作要求。
2. 选择需要的世界、气质、性格、关系和阶层预设。
3. 勾选需要生成的内容模块。
4. 选择总长度和可选的分模块长度。
5. 按需勾选当前角色卡与主世界书作为参考。
6. 点击“开始创作”。
7. 在蓝图编辑区检查并修改每个事件。
8. 通过校验后，导出文件或直接写入 SillyTavern。

点击“在酒馆创建角色”时，扩展会先创建一份不会覆盖现有数据的新世界书，再导入当前选中的主角色或额外可玩角色。User 事件只用于复制 Persona，不会作为角色卡导入。

## 文件

- `manifest.json`：扩展清单
- `index.js`：界面、设置、生成流程与 SillyTavern 写入操作
- `studio-data.js`：预设、模块、长度规则和内置提示词
- `jsonl.js`：增量解析、结构校验、文风检查和 patch 应用
- `compiler.js`：世界书与 V2 角色卡编译器
- `streaming.js`：当前 SillyTavern API 的流式请求适配
- `style.css`：桌面与移动端界面
- `tests/core.test.mjs`：核心解析与编译测试

## 本地检查

```bash
npm run check
npm test
```

扩展运行时不需要安装 npm 依赖。package.json 只用于本地语法检查和测试。

## 数据安全

- 生成结果默认先进入草稿区。
- 只有用户点击写入或创建按钮时，扩展才会修改 SillyTavern 数据。
- 新世界书使用唯一名称，默认不会覆盖现有世界书。
- 绑定当前角色是单独的显式操作。
- 停止生成不会保存不完整世界书或角色卡。
